# EndPortal_Loca
一款用于《我的世界》Java 版的末地传送门坐标计算网页工具，采用白为主、绿色为辅简约设计。输入两组定位数据，即可快速算出末地传送门目标坐标。

✅ 功能特性
- 基于三角定位算法，快速计算传送门坐标
- 简约轻量化 UI，白色主色调 + 绿色辅助配色
- 计算结果弹窗展示，自带渐现弹出动画
- 代码结构清晰，所有 CSS、变量、核心代码附带详细注释
- 纯静态页面，无需后端，本地直接打开预览
- 本项目是纯前端实现的 MC 传送门坐标计算工具，原生 HTML/CSS/JavaScript，无任何依赖。
